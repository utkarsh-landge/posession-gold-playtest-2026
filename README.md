# POSESSION Gold playtest

Playable Unity WebGL build with the Gold visual update. Desktop keyboard and mouse required.

WASD: move. Space: jump as the Spirit. E: possess or eject. Mouse: aim. Left click: use the current body ability.

Original team project: https://github.com/ruturaj-mohalkar-25/POSESSION

Built from local source commit bf30783 on codex/gold-character-rooms. This repository contains only the compiled browser player.
